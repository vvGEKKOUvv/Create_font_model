# PATH / FORM

SVG の閉じたパスを立体にし、OBJ と MTL を書き出すブラウザツールです。処理はブラウザ内で行います。

## インストールせずに使う

1. [PC 用 ZIP をダウンロード](https://github.com/vvGEKKOUvv/Create_font_model/raw/refs/heads/main/downloads/PathForm.zip)します。
2. Windows は ZIP を右クリックして「すべて展開」、Mac は ZIP をダブルクリックします。
3. 展開した `PathForm` フォルダーの `PathForm.html` を Chrome または Edge で開きます。

単体版 `PathForm.html` を PC に保存し、Chrome または Edge で開くと使えます。Node.js やターミナルは不要です。SVG 読み込み、編集、OBJ/MTL 書き出しをローカルで行います。
開発者は `npm run build:standalone` で `dist/PathForm.html` を生成できます。

## 起動

Node.js 22.12 以上（この環境では 24）を使用します。

```sh
cd /workspace/Create_font_model
npm ci
npm run dev
```

ビルド: `npm run build`。幾何処理のテスト: `npm test`。
ブラウザの機能検証: `CHROMIUM_PATH=/usr/bin/chromium npm run test:browser`。
別の環境では `npx playwright install chromium` の後、`npm run test:browser` を実行します。

## 操作

1. Illustrator で文字をアウトライン化し、必要な線を塗りの輪郭に変換して SVG で保存します。`.ai` の直接読み込みには対応しません。
2. SVG を読み込み、対象オブジェクトを選択します。別のSVGを読み込むと現在のシーンに追加します。複数ファイルをまとめて選択・ドロップすることもできます。追加時は既存の設定・位置・カメラを維持します。新しいパスが画面外にある場合は「全体表示」を押してください。
3. 押し出し、ベベル範囲・分割数・プロファイル、角の保持、中抜きを調整します。断面グラフの頂点やハンドルがない場所をクリック、または「頂点を追加」で制御点を増やせます（両端を含め最大16点）。点を選択し、「選択頂点」でリニア／ベジェを切り替えます。ベジェのオレンジ色のハンドルをドラッグして曲がり方を調整できます。「拡大」で大きな編集画面を開きます。点はドラッグまたは矢印キーで移動し、Del（Delete）キーまたは「頂点を削除」で削除します。両端の位置は固定です。
4. 「UV MAP」タブに切り替え、右側の「UV 設定」でスケール、移動、回転を調整します。「UV 頂点編集」を有効にすると、UV の点をドラッグして修正できます。「UV 修正をクリア」で自動生成状態に戻ります。各オブジェクトの色は右側の「マテリアル」で設定します。
5. OBJ と MTL を書き出し、同じフォルダに配置して 3D ソフトで読み込みます。

## オブジェクトの移動・回転・スケール

右側の「オブジェクト選択」または3D画面でオブジェクトを選び、プレビュー上部の「移動」「回転」「スケール」を選択します。移動は軸の矢印、回転はリング、スケールは軸のハンドルをドラッグしてください。W／E／R キーでもモードを切り替えられます。マニピュレータの操作中はカメラの回転を止めます。

右の X/Y/Z 数値でも調整できます。位置は読み込み時からの移動量、回転は度、スケールは倍率です。回転・スケールの中心は読み込み時のオブジェクト中心です。ローカル軸を有効にするとオブジェクトの向きに沿った操作になります。位置・回転・スケールのリセットは専用ボタンを使います。

変換はオブジェクトごとに保持し、ベベルや奥行きの変更後も維持します。OBJには変換済みの頂点と法線を書き出します。

## 画面の配置

SVG 読み込み、オブジェクト選択、位置・回転・スケール、押し出し、ベベル、中抜き、マテリアル、UV設定は右側にまとめています。見出しをクリックすると各項目を折り畳めます。中央は「3D ビューポート」と「UV MAP」のタブで切り替えます。視点操作の慣性を弱くし、ドラッグ後は速やかに停止します。

## パスのリダクションと処理速度

右側の「パスのリダクション」で許容誤差を調整します。単位は元のSVGの座標単位です。0では重複や直線上の不要な点だけを整理し、値を大きくすると輪郭の細かな頂点も削減します。元の輪郭を毎回使うため、値を戻せば削減前の形状に戻せます。表示する頂点数は、SVGの制御点数ではなく、3D化するために分割した輪郭の頂点数です。

尖った角と穴を保護し、削減で輪郭が交差・退化する場合は許容誤差を自動的に下げます。削減前後の数と割合を表示します。上限を超える密なパスは読み込み時に小さな許容誤差で整理し、その値を表示します。原形の完全一致を保証するものではないため、最終形状はプレビューで確認してください。

パラメータの連続入力は70msまとめ、選択したオブジェクトだけを再生成します。輪郭と安全なオフセットの計算は再利用します。色・UV・位置・回転・スケールの変更では立体を再生成しません。書き出し前には未反映の変更を確定します。

重複・直線上の細かい頂点がベベルを無効化していた処理を修正しました。小さいパスには奥行き・ベベル・壁厚の初期値を合わせます。壁厚が大きすぎる場合は、安全に中抜きを作れる値に縮小して警告します。作れない場合は元の輪郭を残して警告し、既存の穴は維持します。「ベベル」に実際に使った幅・壁厚を表示します。

ベベルの「範囲」の最大値は押し出しの奥行きの半分です。値に合わせて、輪郭方向の幅も安全に削れる限界まで広がります。線幅が均一なL字などでは、最大にすると線幅いっぱいに斜面が広がり、中央の稜線が残るフルベベルになります。太さが異なる部分や細かい突起がある場合は、細い部分の限界で幅が制限されます。輪郭限界は交差・穴・細い部分を確認して探索し、計算結果を再利用します。面の退化と表示精度による潰れを避けるため、中央にはごく薄い頂面を残します。初期プロファイルは直線で、頂点のリニア／ベジェ切り替えで変更できます。奥行きと輪郭幅の両方の実効値を表示します。

## スコープ

- 塗りのある SVG 輪郭を対象にします。Illustrator 固有の効果、画像、クリッピング、未アウトライン化の文字などを完全に再現するものではありません。
- UV 編集は全体変換と頂点のドラッグ修正に対応します。UV 座標を共有する点は一緒に動かし、シームは分離します。形状を再生成する設定を変更すると、頂点修正はクリアされます。自動パッキングやテクスチャ編集は含みません。
- 前面・背面・各輪郭の側面に分けて UV を生成します。UV 操作はオブジェクトごとの X/Y スケール、移動、回転です。
- ベベルと壁厚は輪郭の形状によって自動制限されます。警告と実際の幅を確認し、元の SVG の重複・交差があれば修正してください。
- 既存の穴はそのまま使います。「中空にする」は穴のない輪郭に貫通穴を作ります。既存の穴がある場合、壁厚設定による追加の中抜きは行いません。
- ベベルは輪郭オフセットと段階断面による近似です。すべての複雑な輪郭で交差を防ぐ保証はありません。角の保持を外すと角のオフセットを緩和しますが、完全な円弧のフィレットではありません。
- SVG は最大 5 MB、512 パス、256 オブジェクト、各オブジェクトの読み取り時20000輪郭頂点・整理後3000輪郭頂点までです。
- SVG 座標をモデル単位として扱います。OBJ は単位情報を持たないため、読み込み先で単位・スケールを設定してください。

分担と開発ルールは `AGENTS.md` と `agent-team/` にあります。

- オブジェクト別の位置・回転・スケール、3Dマニピュレータ、ローカル軸、数値編集とOBJへの反映に対応しました。

- 選択対象だけの再生成、連続入力の集約、輪郭の再利用、色・UV更新の軽量化に対応。読み込み欄をコンパクトにしました。
- 密なパスのベベル・中抜き処理を修正し、許容誤差で調整するパスのリダクションを追加しました。
- SVGの追加読み込み・複数選択に対応。サンプル表示と説明文を整理し、読み込み・選択欄とパラメータをスリム化しました。
- ベベルの奥行き方向の範囲を輪郭幅から分離し、最大で押し出し中央まで届くようにしました。曲線は空白のクリックで頂点を追加、Delキーで選択頂点を削除できます。
- 最大ベベルで文字の中央に稜線が残るように、輪郭の限界幅を探索するフルベベルに変更。初期カーブを直線にしました。

ベベルの「奥行方向」と「輪郭幅」は独立して調整できます。「正面が合流するまで広げる」を有効にすると、奥行方向が中央で接した後も輪郭幅を広げられ、幅の異なる部分もそれぞれ稜線まで合流します。このモードではカーブを下から上へ単調にしてください。複雑な輪郭で計算できない場合はエラーを表示し、直前のモデルを保持します。
ベジェ頂点のハンドルは「左右独立」「接線」を切り替えられます。ビューポート上部の「ワイヤーフレーム」でポリゴンの辺を表示できます（OBJ の内容は変わりません）。

中空や穴付き輪郭のベベルは、奥行方向を輪郭幅とは独立して調整できます。実効ベベルは押し出し奥行の49%以下とし、中央に2%以上の側面を残します。穴のない通常オブジェクトの合流動作は維持します。実効値と中空時の残る奥行はベベル欄に表示します。

ワイヤーフレームは「線のみ」「線のみ（奥の面を隠す）」「シェーダーに重ねる」を選べます。「線のみ（奥の面を隠す）」では手前の面に隠れた奥の線と、物体の背後のグリッドを描画しません。オブジェクト一覧の表示ボタンで表示・非表示を切り替えられ、非表示のオブジェクトは書き出し対象外です。名前には読み込み時に連番が付き、選択欄の名前入力でリネームできます。OBJ でも名前を保存し、同名には重複防止の番号を付けます。

上部の「元に戻す」「やり直す」で、読み込み、形状・カーブ・UV・マテリアル・位置などの変更、表示切り替え、名前変更を戻せます。履歴は直近60操作で、ページを閉じると消えます。ドラッグ中の連続変更はまとめて記録します。Ctrl/Cmd+Z、Ctrl+Y または Ctrl/Cmd+Shift+Z でも操作できます。入力欄ではブラウザの文字編集用アンドゥを優先するため、モデルを戻すには上部ボタンを使ってください。

ネイティブの Cinema 4D（.c4d）形式への直接書き出しには対応していません。OBJ と MTL を同じフォルダーに保存し、Cinema 4D で OBJ を読み込んだ後、Cinema 4D の保存機能で .c4d にしてください。

中抜きの内側輪郭は、細かな出っ張りや短い辺があっても、正面の壁幅を全面的に縮めない方式で生成します。リダクションを使わずに指定した壁厚を維持でき、外輪郭は保持します。細い箇所では内側の穴が途切れたり複数に分かれることがあります。指定の壁厚で穴が完全に消える場合だけ壁厚を縮小し、警告と実効値を表示します。

中空や既存の穴付き輪郭では、細かな頂点でベベル全体の幅が制限される場合、輪郭差分から傾斜面を作る方式を使用します。局所的に短い辺が消えても、壁厚と外側の輪郭を維持しながら指定したベベル幅を反映します。この方式では戻らないベベルカーブを使用してください。

中空ベベルの曲面は、対応する輪郭点を近い順に結ぶ細かな面で生成し、離れた点を結ぶ対角線による凹凸を抑えています。曲面の共有頂点は角度で重み付けした法線を使い、三角形ごとの陰影差を減らします。輪郭が分裂する箇所は、閉じた形状を維持できる輪郭差分方式を使用します。

輪郭方向の分割はベベル断面の分割数とは別に維持します。内側へ移した輪郭で短い辺が整理された場合にも、元の輪郭に対応する点を保持し、短い辺が局所的に消える場合のみ必要な対応点を補います。キャップと側面でも同じ境界点を共有し、面が少数の頂点へ集中することを抑えます。

対応関係が保たれる輪郭では、元頂点の番号に沿って帯状の面を接続します。全体の平均辺長による一律の頂点追加を廃止し、キャップ処理を局所化しました。ベジェの最低分割数を全体へ配分し、輪郭計算と面生成の結果を再利用します。128点の中空ベジェ・分割8の検証例では52,224頂点から27,648頂点へ減少しました（形状や設定により異なります）。

中抜きなしの輪郭でも、細かな頂点で通常ベベル全体が縮小する場合は安定した輪郭方式を使用し、実際の傾斜面を生成します。ベベルの帯では輪郭間の対応線を拘束として保持し、その内側の対角線を改善します。キャップと稜線の面も境界を保つ三角形分割を使用します。細い形状が実際に消える箇所では三角形が必要になります。

中抜きの壁厚が輪郭より大きい場合は、輪郭の大きさから穴が残る壁厚を探して調整します。中抜きに失敗した場合は穴なし形状へ切り替えず、エラーを表示して直前の有効なモデルを維持します。調整後の壁厚はベベル欄に表示されます。

鋭角がベベルの途中で合流する形状では、穴のある輪郭でも稜線と合流点の高さを計算して面を生成します。輪郭の頂点を削減して段差を隠す処理は行いません。稜線を計算できない輪郭では従来の輪郭差分方式へ切り替え、同じ輪郭での計算失敗を記録して再編集時の再試行を抑えます。密な輪郭では最初の計算に時間がかかる場合があります。

稜線の計算結果は元の輪郭と照合し、ベベルと側面の境界が一致しない場合には使用しません。中抜きした密な曲線で稜線の面が欠落する場合も、元の境界を共有する輪郭差分方式に切り替えます。

輪郭差分方式の三角形分割は倍精度の座標で計算し、分割前の座標丸めによる面の欠落・重複を防ぎます。描画精度で同じ点に潰れる退化面だけを除き、元の輪郭頂点は削減しません。稜線方式と輪郭差分方式の両方で、生成した面の共有辺を検証します。

「状態を保存」でパス、全オブジェクトの設定・変形・UV編集・表示状態・カメラを `.pathform` ファイルに保存し、「状態を読み込む」で再開できます。読み込みは現在の作業を置き換えますが、アンドゥで戻せます。不正なファイルでは現在の作業を保持します。「選択オブジェクトを複製」で独立した設定を持つコピーを作成します。

「OBJ の保存先を指定」を有効にすると、対応ブラウザではフォルダーを選択し、OBJとMTLを一緒に保存できます。同名のファイルがある場合は番号を付け、上書きを避けます。保存先選択が利用できない環境ではブラウザのダウンロードに切り替えます。`.c4d` の直接書き出しは未対応です。Cinema 4DでOBJを読み込み、Cinema 4Dから `.c4d` として保存してください。

「輪郭のオフセット」は正の値で外側、負の値で内側へ輪郭を動かし、押し出しの奥行きは変更しません。穴の消失、輪郭の分裂・消滅が起きる値は縮小して適用量を表示します。鋭角の異常な伸びを防ぐため、極端な尖端の結合部は短く切り詰める場合があります。

尖端の山型ベベルは合流する稜線を計算し、段階状の水平面を抑えます。同時合流の計算に失敗する場合は微小な計算公差を使用しますが、元の輪郭と穴の境界は変更しません。葉形の検証例では内部稜線の公差は約0.0003単位です。面の再利用と不要な安全幅探索の遅延によって、パラメータ変更時の計算を削減しています。

右側は中抜きをベベル数値の直下に配置し、ベベルカーブを独立した折り畳み項目にしています。パラメータの余白・行高・入力欄をコンパクトにし、カーブの編集領域は維持しています。

オブジェクトを選び「上へ」「下へ」で一覧とOBJの順序を変更できます。位置や設定は変わらず、状態ファイルに順序を保存し、アンドゥ・リドゥで戻せます。

パスのリダクションで許容誤差を調整し、「パスに適用」で読み込んだパス自体の頂点を削減します。プレビューと同じ形状を維持したまま許容誤差を0へ戻し、削減後の輪郭を保存・複製します。カーブはプレビューに使う輪郭の線分に置き換わります。元のパスはアンドゥで戻せます。

ベベルカーブの「調整対象」で外側・内側を切り替えて独立編集できます。共有する面は二つのカーブを連続補間し、合流部の隙間を防ぎます。内外カーブと選択中の調整対象は状態ファイルに保存します。新規オブジェクトの初期カーブは全頂点ベジェ・接線モードの直線です。既存の保存データのカーブは変更しません。直線ベジェは余分な分割や反復計算を省いて処理します。

マテリアルの「質感」でオブジェクトごとに標準／金属を切り替えられます。「環境」でスタジオ・ソフトボックス・屋外・夕景の反射を切り替えます。環境は全オブジェクトに共通で、外部ファイルや通信は不要です。質感と環境の選択は状態ファイルに保存します。金属の反射にはオブジェクトの色も影響します。OBJ／MTLは形状と色を保存しますが、この画面の金属シェーダーや環境反射は再現しません。

中抜きベベルの面接続を安全に生成できない場合は、穴を維持した通常ベベルへ切り替え、輪郭幅を安全な最大幅に制限して警告します。

元のパスに穴があっても「中空にする」を利用できます。外周と既存の穴の周囲に壁を残し、その間を追加でくり抜きます。壁が複数の部分に分かれる場合も同じオブジェクトとして編集・保存・書き出しします。元の穴は保持します。

「オブジェクトのリダクション」の削減率で、生成後のメッシュの面数を減らせます。パスのリダクションとは別の機能で、元のパスとベベル設定は保持します。0に戻すと元のメッシュを再生成します。穴や尖った角、UV境界を保護し、面の反転や接続の破損を避けるため、指定率まで減らせない場合があります。実際の面数と削減率を表示します。削減率の変更ではUV頂点修正をクリアし、削減後のUVを編集できます。設定は保存・複製・アンドゥに対応し、OBJには削減後のメッシュを出力します。

押し出しはオブジェクトの原点を中心に、前後へ奥行きの半分ずつ広がります。奥行きを変えても移動・回転・スケールの中心を維持します。新規オブジェクトの奥行き方向の原点は0で、旧状態ファイルの原点位置は保持します。


中抜き・穴付き形状のベベルは、各部分の中間の稜線を計算して生成します。幅を増やすと、すでに合流した部分は輪郭方向の稜線位置を保ち、幅の広い部分はそれぞれの稜線まで広がります。奥行方向は独立して調整できます。面の接続を安全に計算できない場合は、幅を制限した通常ベベルへ切り替えて警告します。内側の曲線を保つ設定は削除し、以前の状態ファイルに含まれていても適用しません。

ベベルカーブは空白クリックで頂点を追加し、選択頂点をDelキーで削除します。追加・削除ボタンを取り除き、拡大ボタンを編集欄の右上へ配置しました。

ベベルカーブのハンドル設定を右寄せにし、尖った角を保持の項目を削除しました。新しく読み込むオブジェクトの初期カラーはグレー（#B0B0B0）です。保存済みの状態ファイルや編集したカラーは維持します。

ベベル面は、凸形の稜線面を帯ごとに分割してから三角化し、不要な対角線上の頂点を減らします。主方式の直線ベベルでは、平面を増やすだけの中間分割を省きます。曲がったベベルカーブの分割と元輪郭の頂点は維持します。尖った輪郭角と外周・内周が合流する稜線では法線を分離し、エッジを丸く見せる陰影の混合を抑えます。面接続を保つため、代替の輪郭差分方式では従来の分割を維持する場合があります。
メッシュのリダクションでも、浅い稜線の硬い法線境界を保護し、稜線をまたいで面をまとめることを防ぎます。

ベベルの分割数は中間エッジループの本数です。0は中間ループなし、1は中央に1本、2は均等な3分割になります。曲線に沿う断面の長さを基準に配置し、ベジェの曲率によって自動でループを増やしません。内外で異なるカーブの場合は、共有ループの本数を保つため両曲線の平均弧長を使います。クリックで明示的に追加したカーブ頂点のエッジは例外として維持します。初期カーブの中央頂点は追加エッジ扱いにしません。輪郭自体の頂点や稜線の接続に必要な三角形は、この断面のループ本数とは別です。

同じ内外カーブの評価表と共有頂点の計算を再利用し、形状再生成中の仮オブジェクトでワイヤーフレームを重複生成しないようにしました。256頂点の中抜き形状・分割3の参考計測で、パラメータ6回変更は889msから363ms、面数は24,576から9,216へ減少しました。実際の速度は輪郭・カーブ・環境により異なります。

ベベル帯の不要な頂点を整理するため、凹形の稜線面でも、同じ平面上の三角形を境界から再分割します。元輪郭・稜線・カーブ位置を保護し、事前の対角線から生じた人工的な交点だけを取り除きます。平面でない面や、接続を維持できない場合は元の分割を保持します。

輪郭差分方式では、消えた短い辺を再投影する補助頂点がほぼ同じ位置へ集中しないよう整理しました。実際のオフセット角と元輪郭の頂点は変更しません。400頂点の検証例では、2050→1974面、極端に細い三角形は55→4面でした。形状によって整理できる量は異なります。

旧状態ファイルのベベル分割数は、従来の帯数を維持するように新しいループ本数へ変換します。状態ファイルの保存形式はバージョン2です。

3,000頂点を超えるパスは、元の頂点数と削減の警告を表示し、承認した場合だけ輪郭と穴を保ちながら処理可能な数へ削減して追加します。キャンセル時は作業を保持します。承認後は削減済みのパスを保存します。200,000頂点を超える入力や、穴・尖った角を保ったまま削減できない入力は読み込みを中止します。

中抜きの鋭角の角は、オフセット時に先端を途中で切り落とさず、二等分線上の頂点対応を保ちます。対向する輪郭と衝突する部分は、穴と面の接続を維持する処理を使います。

中抜きの輪郭差分方式でも、鋭い外周先端から伸びる稜線を実際のメッシュエッジとして生成します。元輪郭の稜線と、それに接続する必要な輪郭側の分岐で面を分け、先端の両側が同じ平面にならないようにします。稜線の両側の法線は分離し、曲線の滑らかな補助分岐には強制的な硬い陰影を付けません。内外で異なるベベルカーブ、分割数0・1・2、小さな縮尺、OBJ出力を検証しています。

補正は穴との競合またはベベルの平坦な正面に達するまでです。外周の稜線計算は再利用しますが、初回には追加の計算が発生します。読み込み可能な輪郭では512頂点を超えても稜線全体を計算します。外周稜線を計算できない場合は、先端の最初の直線区間を補正します。面の接続を維持できない区間は元の分割を保持します。オブジェクトのリダクションでは曲線状の稜線が許容誤差内で簡略化される場合があります。

748頂点の曲線SVGでも、外側の先端から複数の区間を通る稜線を検証しています。稜線復元の計算では、離れた面を処理せず、置換する領域の境界を検証してから最後に全体の接続を確認します。壁厚20の参考計測では、復元版の初回生成が最適化前10.9秒から2.9秒へ短縮され、位置・法線・UVデータは一致しました。実際の速度は輪郭・設定・PCによって異なります。
